## 验证命令与证据

- `mvn -o test`：全模块编译通过，71 项测试通过，0 失败。完整日志：`logs/sse-final-maven.log`。
- `AiNotificationRedisIT`：单独显式启用，按 [通知与 ACK 契约](sse-notification-contract.md) 的命令运行；4 项通过。五种连接结果使用 bridge 测试替身，Redis、消费者、handler、重试及重放使用真实实现。
- Redis 集成最终复测：4 项通过，0 失败，日志：`logs/sse-final-redis.log`。故障注入用例中的 ERROR 堆栈是预期异常证据，验收以测试断言和退出码为准。
- 前端 `npm test`：22 项通过；`npm run build`：类型检查和生产构建通过。
- `npx playwright test tests/chat-contract.spec.ts --project=live`：2 项通过。浏览器验证消息/附件既有流程、50 条通知突发的最大刷新并发 1、断线重连握手同步。API/SSE 响应为明确模拟。

Java 原生 XML/文本证据位于各模块 `target/surefire-reports/`。Redis 测试只读连接配置，不输出口令；每例使用 UUID 前缀及唯一组/消费者，结束逐个删除自己的三个明确 Redis 键，无 `FLUSHDB`，不消费既有业务队列。

Tomcat 的 `getConnectionCount()` 包含 acceptor 预留名额，不能把其严格为 0 当作空 socket 判据。停读测试通过测试协议子类查询 endpoint 的实际连接集合，且在客户端 finally 关闭之前断言归零。

## 清理

移除无调用的连接关闭原因包装方法、失效定时清零空方法、未使用优先级 code/weight、未使用失败时间字段与 import/测试局部变量。`slowCount` 命名改为 `consecutiveFailures`。保留旧配置项以兼容已有 YAML，但其定时清零语义已停用并注明。

完成验收后逐个移除本轮临时 JUnit 启动器源码/对应 class，以及已由本记录替代的临时实施计划；不删除目录。历史验收、证据 JSON、迁移 SQL、手工联调脚本、原图和用户未跟踪的 Word 文件保留，不以“未被代码引用”推定无用。

## 限制

- 写入强制终止默认处于仅观测模式；启用需配置应用及传输预算。已验证 Tomcat 10.1.44 HTTP/1.1 NIO，connector 预算也影响其他请求读取。
- 预警通过 JMX/日志供采集，没有接入外部通知平台；窗口 P99 是十二桶估计。生产阈值须结合正常、弱网及突发分布校准。
- Redis Pending 自动接管尚未实现；服务不可用时原记录保留，需人工确认原消费者停止后恢复。
- 未对无实际生产者或会话键契约的 READ/TYPING 事件猜测合并。
- 未验证生产代理、HTTP/2、长时资源增长、重连风暴、多标签驱逐和生产容量；本次结果不支持生产承载量或最终告警阈值结论。
