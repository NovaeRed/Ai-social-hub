## 文件与测试数据

前端代码位于 `ai-social-web/`，运行说明见其 README。审计脚本位于 `ai-social-web/scripts/`，浏览器与单元测试位于 `ai-social-web/tests/`。

所有联调写入均来自本次新建测试账号，测试账号凭证/会话文件在 Git 忽略的 `.local/`；文件上传由后端写入 `data/chat-files/`，该运行目录已加入忽略规则。历史消息群因后端缺陷无法解散，保留其测试记录供复现。未批量删除文件或直接清理数据库。

为保留现有产物，Vite 配置 `emptyOutDir:false`，测试输出使用独立的时间戳目录；多次构建产生的旧静态资源不会被自动清除。
