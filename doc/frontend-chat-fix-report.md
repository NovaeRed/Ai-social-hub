# 聊天交互修复与验证

日期：2026-10-23。分支：`codex/frontend-chat-ux`。本报告不将本机偏好宣称为服务端持久化能力。

## 修复结果

- 会话行支持左滑显示置顶、取消置顶和移除菜单；保留更多按钮及右键入口。手势采用横纵方向判断，正常纵向滚动不触发菜单，手势结束不会误打开会话。
- 补齐会话菜单、置顶标识、消息操作按钮、多选工具栏和转发目标列表在小屏下的布局。会话与聊天保持左右排列。
- 消息长按或更多按钮进入多选，滚动移动会取消未完成的长按。最多选择 20 条，长按、右键和复选框路径统一限制；第 21 个复选框恢复为未选状态，空选择禁用删除和转发。
- 消息确认弹窗通过 Teleport 放到 body，避免聊天区域 overflow 裁剪；提供焦点限制、关闭后的焦点恢复、Escape 和背景滚动锁。删除确认明确说明仅隐藏本账号在当前浏览器的记录。
- 转发使用操作开始时的消息快照；部分成功时只重试剩余消息。失败消息复用临时编号；文件先鉴权下载，再上传到接收会话。上传缓存和临时编号以目标会话及源消息共同区分，避免失败后换接收对象复用错误附件。
- 本机偏好按账号隔离。修复损坏 localStorage、顶层 null 和 hidden 非数组导致页面崩溃的路径。修复从好友重新发起聊天时，已移除会话未恢复到列表的问题。
- Playwright 可通过 `PLAYWRIGHT_DEMO_PORT` / `PLAYWRIGHT_LIVE_PORT` 隔离测试服务，默认端口不变。

## 验证

- `npm run build` 通过。
- 现有 11 项演示页面回归通过。
- 新增聊天用例覆盖 375 / 580 / 1024 像素下的左滑、置顶刷新、移除刷新、好友入口恢复、长按多选、转发确认和本机删除刷新。
- Chromium 真实触屏事件验证横向滑动及长按后继续点选其他消息；移动超过阈值时不误选。
- 验证 20 条限制、空选择禁用、损坏本机数据与取消多选。
- 独立模拟 API 用例验证两条消息中部分成功，重试不重复首条、附件只上传一次、临时编号重用。此项验证前端请求契约，不代表后端支持原生合并转发。

## 服务端限制

目前置顶、移除和逐条隐藏以 localStorage 实现，不跨设备同步；界面和确认文案明确说明“仅此浏览器”。后端尚需提供会话偏好和按条消息隐藏接口。消息转发沿用发送接口逐条发送，文件重新上传；服务端批量/合并转发及原子性需另行补充。
